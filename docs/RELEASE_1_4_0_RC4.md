# 1.4.0-rc4 integration candidate

This source combines the schema3 short-road heading candidate with confirmed-street display
retention, compact movable floating panels and durable queue/location diagnostics.

The display keeps a confirmed named street through uncertainty. A different named or unnamed
road requires two distinct valid GPS fixes; an unnamed road shows only the locality. New trip,
disabled GPS or ten seconds without a valid fix clears street memory. Raw resolver quality,
gate admission, cooldown, reservations and action priorities retain their independent contracts.

Private diagnostic records explain queue waiting and dispatch even without an attached host.
They are bounded by size and age. Cancellation history is diagnostic only and cannot consume,
restore or replay an action. The separate Wispr adapter does not block Dudu media scheduling.

Version code30 is reserved for this candidate. Build, host regression, emulator, exact-map
compatibility, privacy and installer evidence must be recorded before radio deployment.
Physical driving, steering-button, vendor sleep and overnight tests remain pending until
observed on the target radio. No APK, map, private trace or device configuration is published.
